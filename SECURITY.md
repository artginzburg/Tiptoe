# Security Policy

Tiptoe installs software updates unattended, so it deserves scrutiny — reports are very welcome.

Please report vulnerabilities privately via [GitHub Security Advisories](https://github.com/artginzburg/Tiptoe/security/advisories/new) rather than a public issue. You can expect an initial response within 72 hours; please leave time for a fix to ship before public disclosure.

Only the latest release is supported. Issues in Sparkle itself belong upstream at [sparkle-project/Sparkle](https://github.com/sparkle-project/Sparkle).
